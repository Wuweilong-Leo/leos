# 启动与引导模块功能设计说明书

## 1 文档信息

| 项目 | 内容 |
|------|------|
| 模块名称 | 启动与引导（Boot） |
| 模块路径 | arch/boot/i386/ |
| 文档版本 | V1.0 |
| 编写日期 | 2026-07-03 |

## 2 模块概述

### 2.1 目的

从 BIOS 加电自检完成到内核获得控制权，完成实模式→保护模式→分页模式的处理器状态转换，并将内核从磁盘加载到正确地址空间执行。

### 2.2 适用范围

系统上电启动的唯一入口，仅在开机时执行一次。

### 2.3 设计约束

- MBR 仅 512 字节，含分区表和启动签名后可用空间约 440 字节
- Loader 在实模式下运行，只能使用 BIOS 中断和端口 I/O
- 开启分页瞬间必须保证指令流地址连续，否则 CPU 执行未定义行为

## 3 功能描述

### 3.1 功能列表

| 功能编号 | 功能名称 | 功能描述 |
|----------|----------|----------|
| BOOT-001 | MBR 加载与执行 | 由 BIOS 加载到 0x7C00，设置实模式执行环境 |
| BOOT-002 | 实模式→保护模式切换 | 关中断、加载 GDT、CR0 置 PE 位、远跳转 |
| BOOT-003 | Loader 加载 | 读取 LBA2 起的 Loader 到内存 0x9000 |
| BOOT-004 | 保护模式磁盘读取 | 使用 LBA28/LBA48 端口 I/O 读取硬盘扇区 |
| BOOT-005 | 初始页表构建 | 建立低 2M 恒等映射和高端映射，设置自映射项 |
| BOOT-006 | 分页模式开启 | CR0 置 PG 位，CR3 载入页目录物理地址 |
| BOOT-007 | 内核加载 | 读取内核 ELF 文件到 0xC0001000 并跳转 |

## 4 处理逻辑

### 4.1 MBR 执行流程

```
开始
  │
  ├─ [BOOT-001] 设置段寄存器（DS=ES=0），建立栈（SS:SP=0:0x7C00）
  │
  ├─ [BOOT-002] 切换到保护模式
  │    ├─ 关中断（cli）
  │    ├─ 加载 GDT（lgdt）
  │    ├─ CR0.PE 置 1
  │    └─ 远跳转清流水线，CS=0x08
  │
  ├─ [BOOT-003] 读取 Loader
  │    ├─ 设置 ES:BX=0x9000
  │    └─ 调用 BIOS INT 13h 读取 LBA2~LBA8
  │
  └─ 跳转到 0x9000 执行 Loader
```

### 4.2 Loader 执行流程

```
开始
  │
  ├─ 设置保护模式段寄存器（DS=ES=0x10）
  │
  ├─ [BOOT-004] 读取内核
  │    └─ 调用 OsReadDiskM32(secId, secNum, dst)
  │         优先使用 LBA28，失败尝试 LBA48
  │
  ├─ [BOOT-005] 构建初始页表
  │    ├─ 清空页目录和页表
  │    ├─ 页目录[0] → 第一张页表（低 2M 恒等映射）
  │    ├─ 页目录[768] → 同一张页表（0xC0000000 高端映射）
  │    ├─ 页目录[1023] → 页目录自身（自映射）
  │    └─ 第一张页表：512 项，每项映射 4K，共 2M
  │
  ├─ [BOOT-006] 开启分页
  │    ├─ CR3 载入页目录物理地址
  │    ├─ CR0.PG 置 1
  │    └─ 此时 0x00000000 和 0xC0000000 同时有效
  │
  └─ 跳转到 0xC0001000 执行内核入口
```

### 4.3 双映射切换原理

```
开启分页前：CPU 在实模式/保护模式，EIP 在低地址（~0x9000）
开启分页后：
  - 低地址 0x00000000~0x00200000 映射到物理 0~2M（恒等映射）
  - 高地址 0xC0000000~0xC0200000 映射到物理 0~2M（高端映射）
  两条路径同时有效，EIP 所在地址不中断
内核入口在 0xC0001000，跳转后完全运行在高地址空间
```

## 5 数据设计

### 5.1 磁盘布局

| LBA 范围 | 内容 | 大小 | 说明 |
|----------|------|------|------|
| 0 | MBR | 512B | 引导扇区，含分区表和 0x55AA 签名 |
| 1 | 保留 | 512B | - |
| 2~8 | Loader | 3.5KB | 保护模式加载器 |
| 9+ | 内核 | 按需 | ELF 格式内核映像 |

### 5.2 初始页表映射

| 虚拟地址 | 物理地址 | 页目录项 | 说明 |
|----------|----------|---------|------|
| 0x00000000~0x001FFFFF | 0~2M | [0] | 恒等映射，保证开启分页后不崩溃 |
| 0xC0000000~0xC01FFFFF | 0~2M | [768] | 高端映射，内核运行地址 |
| 0xFFC00000~0xFFFFFFFF | 页表自身 | [1023] | 自映射，运行时访问任意页表项 |

## 6 错误处理

| 错误场景 | 处理方式 |
|----------|---------|
| 磁盘读取失败 | LBA28 失败尝试 LBA48（当前实现仅用 LBA28） |
| 页表设置错误 | 无检测，启动阶段错误直接导致崩溃 |

## 7 设计决策

| 决策 | 理由 |
|------|------|
| 双映射（低地址+高地址同时映射） | 开启分页瞬间 EIP 还在低地址，需要低地址映射保证指令流连续；跳转到内核后完全在高地址运行 |
| 自映射（页目录最后一项指向自身） | 使得页表项可通过虚拟地址直接访问，无需物理地址运算：PDE=0xFFFFF000+idx×4，PTE=0xFFC00000+偏移 |
| Loader 中只映射 2M | 启动阶段内核代码+数据远小于 2M，运行后由页表模块按需扩展 |
